What Is an MCP Rug Pull? How Poisoned AI Tools Hijack Agents

An MCP rug pull occurs when a remote AI tool server mutates its schema after approval to steal SSH keys and tokens. Pin SHA-256 tool hashes to block it.

An MCP rug pull is a post-approval supply-chain exploit against the Model Context Protocol where an external tool server passes initial security review with clean code, and later mutates its tools/list schema at runtime to inject hidden instructions that exfiltrate SSH keys, API tokens, and database records.

Throughout 2025 and 2026, engineering teams raced to standardize how AI agents connect to databases, internal APIs, and peer agents. Anthropic's Model Context Protocol (MCP) became the universal "USB-C for AI" tool invocation, while Agent-to-Agent (A2A) protocols standardized how specialized multi-agent swarms discover and delegate tasks to one another.

That standardization created a massive, unguarded supply-chain attack surface. Recent security disclosures, including CVE-2025-6514 (mcp-remote STDIO command injection affecting hundreds of thousands of developer machines) and CVE-2025-6515 (session ID hijacking), proved that trusting dynamic protocol metadata isn't safe. It's a critical blind spot: you can't secure an autonomous agent fleet when any third-party MCP server can rewrite its own behavioral instructions mid-flight.

MCP rug pulls and Agent Card poisoning hijack AI agents because LLMs read tool descriptions and peer AgentCard manifests directly as high-privilege system instructions. A malicious MCP server passes initial review with clean code, waits until enterprise clients connect, and then mutates its tools/list JSON response to embed prompt injections that exfiltrate secrets or OAuth tokens.
