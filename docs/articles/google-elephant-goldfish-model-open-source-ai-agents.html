Google Elephant-Goldfish Model (EGM): Prompts & Python Code

Google’s open-source Elephant-Goldfish Model ([google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model), Apache-2.0) eliminates self-review bias in AI engineering by separating full-history plan drafting (the Elephant) from zero-history cold verification (the Goldfish). Instead of letting one AI chat session write and review its own work, EGM deletes the chat history before spawning fresh reviewer subagents, catching 90% of unstated assumptions before a single line of code is written.

Have you ever written a long email or contract, read it over three times, and still missed an obvious mistake, only for a coworker to spot it in 10 seconds? Your brain remembers what you *meant* to write, so it mentally fills in what's missing on the page.
