pgvector HNSW Memory Cliffs: WAL Bloat & Iterative Scans

Fix PostgreSQL pgvector 0.8+ HNSW maintenance_work_mem disk spills, 4.2x WAL bloat, and empty multi-tenant filtered queries via halfvec and iterative scans.

Imagine asking a corporate librarian for ten binders on "Q3 liquidity stress tests," only to watch them grab forty binders first and check your security badge *afterward*, tossing out thirty-nine binders owned by other teams and handing you one page. That post-filter starvation, paired with maintenance_work_mem disk spills and 4.2x Write-Ahead Log (WAL) amplification, breaks PostgreSQL pgvector past five million rows unless you enable halfvec (FP16) quantization and pgvector 0.8+ iterative HNSW scans.

Consolidating relational metadata and vector embeddings inside PostgreSQL via pgvector eliminates synchronization drift between transactional tables and external vector stores. At 500,000 chunks, you don't feel memory pressure: a standard vector(1536) Hierarchical Navigable Small World (HNSW) index fits inside default Linux page caches and returns top-10 Approximate Nearest Neighbor (ANN) results in 2.4 milliseconds.

Trouble strikes abruptly between 5 million and 15 million vectors (1,536 to 3,072 dimensions) when operators assume B-Tree tuning rules still apply. Unlike sequential B-Tree indexes that split cleanly across 8 KB disk pages, an HNSW index isn't append-localized; it's a dense, multi-layered proximity graph where every vector insert updates bidirectional neighbor pointers (m = 16 to 32 edges per node) across scattered memory pages. Crossing physical memory thresholds triggers three compounding production failures:

1. The maintenance_work_mem Graph-Build Cliff (48x Slowdown): During CREATE INDEX USING hnsw or REINDEX, PostgreSQL must hold the active graph structure inside maintenance_work_mem. Once a 10M-row FP32 graph (~68 GB) exceeds maintenance_work_mem, Postgres emits NOTICE: HNSW graph no longer fits into maintenance_work_mem and falls back to random disk page hops, stretching a 22-minute build into 18+ hours.
